# Fulfillment

Picks, packs and ships orders from the warehouse.

## Language

**Shipment:** One or more parcels sent to a customer in a single dispatch.
*Avoid*: delivery; consignment

**Pick List**:
The list of products a picker collects for one shipment.
It is printed at the start of each wave.
Avoid: picking slip

**Wave**:
A batch of pick lists released to the warehouse together.
